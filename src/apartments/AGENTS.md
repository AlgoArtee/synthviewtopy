# Apartment scene visual review

For new or substantially changed 3D apartments, use a separate realism review agent. It must inspect screenshots captured from the actual running room, compare supplied references and layout, and give an honest score out of 10. Accept visual realism only at 8/10 or higher.

Use at most three formal graded scene-review rounds per requested scene. After a failed round, address the concrete findings before the next review. If the third review remains below 8/10, report the actual result and remaining limitations; do not claim acceptance or run additional graded reviews.

Preserve the scores, screenshot paths, findings and fixes with the room's documentation. Build checks and geometry preflights are separate from formal visual grading.
